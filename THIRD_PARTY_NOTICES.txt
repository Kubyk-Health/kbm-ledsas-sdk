The SDK's wheel and source distribution do not contain the listed
third-party packages:
`pip install` pulls them from PyPI, and each ships its own LICENSE file
inside the install directory (e.g.
`venv/lib/python3.11/site-packages/aio_pika-*.dist-info/LICENSE`). The
URLs above link to each project's source, which also carries the full
license text.

Container images are different: the LEDSAS base image
`ghcr.io/kebormed/kbm-ledsas-base-direct` (see the README, "Container
base image") contains the SDK with all of these packages already
installed, so an image built on it redistributes them. Their license files are inside the image, under the
Python site-packages directory (`<pkg>-*.dist-info/`); keep them when
you ship an image, and include this notice with it.

This notice covers only the SDK's Python packages. The base image also
contains an operating system (Alpine Linux) with its own packages, the
Python runtime, and Python's own packaging tools (setuptools, wheel,
packaging), each under its own license; several of the OS packages are
under GPL or LGPL licenses (for example busybox, the shell and core
utilities, GPL-2.0-only), whose terms on source availability apply
when you redistribute an image. They are not listed here. To list what
an image contains, with each package's license, run:

  docker run --rm --entrypoint sh <your image> -c 'apk list --installed'

for the OS packages (each line names the package's license in parentheses),
and look in the site-packages `*.dist-info/` directories for the Python
packages; a software bill of materials tool (for example syft) lists
both. Alpine's package sources are published by the Alpine Linux
project. Open an issue in this repository if you need a notice for the
base image.
